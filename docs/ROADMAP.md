# Roadmap — Neon Arena 3D

## Afgerond

- [x] Three.js 3D-scène met WebGL-renderer
- [x] First-person camera en Pointer Lock
- [x] WASD-beweging en arena-grenzen
- [x] 3D-arena met vloer, muren, licht en schaduwen
- [x] Raycast-schieten met crosshair en muzzle flash
- [x] Low-poly zombies met eenvoudige AI en loopanimatie
- [x] Score, health-hartjes, particles, pauze en game-over
- [x] Ammo-magazijn van 30 kogels met handmatig/automatisch herladen
- [x] Schiet- en damage-geluidseffecten via Web Audio API
- [x] Levels met `level × 5` zombies, levelvoortgang en levelmelding
- [x] Minimale spawnafstand tot de speler

## Volgende fases

- [ ] Achtergrondmuziek en aanvullende geluidseffecten
- [ ] Verschillende vijandtypen en unieke zombievarianten
- [ ] Power-ups en meerdere wapens
- [ ] Modellen, textures en betere animaties
- [ ] Mobiele bediening en performance-optimalisatie
- [ ] Online publiceren met een vaste Three.js-build
